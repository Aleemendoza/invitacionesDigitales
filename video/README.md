# Papeleta — Reel de lanzamiento

Composición Remotion vertical de 24 segundos (1080×1920, 30 fps) creada a partir de capturas reales de Papeleta.

## Comandos

```powershell
pnpm install
pnpm audio
pnpm studio
pnpm render
```

La composición principal se llama `PapeletaLaunch`. Las siete escenas también están registradas individualmente para poder ajustar su contenido desde Remotion Studio.

El audio es una pista original generada localmente e incluye beat, transiciones, tap, confirmación y cierre. No se incorporó voz en off porque era opcional y el video está diseñado para comprenderse sin sonido.
